# Thank you
Thank you to everyone who has sent a report with the new Report a bug button. Every fix below came from one.
# New
- The Slide Grid scrolls with the song, keeping the live slide in view with the next few slides below it. Scroll or click in it yourself and it waits a few seconds before following again.
- The playlist on the ProPresenter page follows the live slide the same way.
# Fixed
- Slide Preview shows the picture of the slide that's actually live. On songs whose arrangement reorders or repeats sections, the slide number was right but the picture belonged to a different slide.
- Saving Settings no longer disconnects every phone and kiosk. If phones and kiosks really can't connect, Settings, Browser Access now says why, and which app is using the port.
- Print a poster on the crew step of setup now prints the join poster. Before, the button did nothing.
- When the computer won't open the audio input, the SPL meter now says what to check (microphone permission, the input plugged in) instead of doing nothing.
- A song that appears twice in a playlist, like a reprise, no longer shows both copies as live.
