# New
- ATEM switchers. Connect a Blackmagic ATEM in Settings, ATEM Switcher, and add the ATEM Switcher tile to a dashboard. It shows what's on Program in red and Preview in green, with the names you gave your inputs. Tap a source to put it on Preview, then Cut or Auto takes it live. Thank you, Ryan, for asking for it.
- Stream Deck buttons for the switcher: Cut, Auto and Preview a source.
# Safer
- Browser Access is harder to break into. Every place that checks a password, including camera feeds and Stream Deck links, now slows down repeated wrong guesses, and phones outside the building each get their own limit.
- Crew phones no longer receive the Church Online connection key. It stays on the booth computer.
- A volunteer's PIN gets five tries in total, however their name is typed.
# Fixed
- Soundcheck playback keeps one layout. Each channel comes back on the same console input every time, so one Dante preset and one Virtual SoundCheck matrix fit every recording.
- The LIVE badge on the OBS tile and other warnings now show in red, as they always should have.
# Also
- An anonymous daily count, so we know how many booths use ProDeck. It sends a random ID, the version and Mac or Windows, and nothing about your church. Turn it off in Settings, Help & support.
