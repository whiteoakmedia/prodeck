# New
- The Slide Grid now shows the whole playlist with a picture of every slide, like the ProPresenter page. It follows ProPresenter from playlist to playlist and keeps the live slide in view, and you can click any slide to put it live.
- Crew phones and kiosks without control permission see the slides but can't put them live.
- Prefer the old compact view? Edit the dashboard and set the Slide Grid to show only the live song, as text.
