# Fixed
- ProDeck could run out of network connections after a long day of looking for camera feeds, and then stop finding anything new. Fixed.
- A rare crash in finding devices on the network, caused by an unusual message from another device, is fixed.
- Crew phones and kiosks opening the Auto-Follow page no longer cause errors in the background.
- A camera scan that fails now says why, instead of quietly showing nothing.
- ProDeck now checks for updates every few hours, so a booth left open for days still hears about new versions.
